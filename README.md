# ゴルフレッスン サブスク管理ツール

## セットアップ手順

### 1. スプレッドシートを作成
Google ドライブで新規スプレッドシートを作成する。

### 2. GAS にコードを貼り付ける
スプレッドシート → 拡張機能 → Apps Script を開き、`gas/Code.gs` の内容をエディタに貼り付けて保存。

### 3. シートを初期化する
GAS エディタで `setupSheets` 関数を選択して「実行」。  
`calendars` シートにサンプル行が作成される。

### 4. カレンダー ID を入力する
スプレッドシートの `calendars` シートを開き、各プランの Googleカレンダー ID を入力する。  
（カレンダー ID は Googleカレンダー 設定 → 該当カレンダー → 「カレンダーの統合」で確認）

### 5. 会員情報を入力する
`members` シートに会員情報を入力する。メールアドレスは予約時と完全一致が必要。

### 6. GAS をウェブアプリとしてデプロイする
1. GAS エディタ右上「デプロイ」→「新しいデプロイ」
2. 種類：ウェブアプリ
3. 実行ユーザー：自分
4. アクセスできるユーザー：**全員**
5. 「デプロイ」をクリックして URL をコピー

### 7. トリガーを登録する
GAS エディタで `setTrigger` 関数を実行（毎日 23:00 に自動同期が走る）。

### 8. HTML ツールで URL を設定する
`index.html` をブラウザで開き、右上「⚙ URL設定」からデプロイ URL を貼り付けて保存。

---

## ファイル構成

```
golf-lesson-manager/
├── index.html     # メイン管理ツール（ブラウザで開くだけで動く）
├── gas/
│   └── Code.gs   # GAS コード（Apps Script に貼り付ける）
└── README.md
```

## 注意事項

- GAS のアクセス権限は「全員」に設定すること（HTML から直接 fetch するため）
- メールアドレスの照合は小文字で統一（予約時と members シートで一致が必要）
- 月次更新処理（持越し計算）は GAS 側が担当。HTML は表示のみ
- レッスン自動取得漏れ時は HTML ツールの「⛳ レッスン使用」ボタンで手動追加可能
